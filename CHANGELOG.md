# Changelog

Every release is a git tag (vX.Y.Z). Newest first.

- **v2.53.1** — wrong-password lockout now grows each time (1, 2, 4, 8, then 15 minutes) instead of always 1 minute.
- **v2.53.0** — web side panel grouped into Browse / People / Play & watch / More (Hindi too); the Discord-style host name chip is gone from the header.
- **v2.52.1** — in-app browser: page errors go to the app log (Activity tab, lines starting "web"); debug builds can be inspected from chrome://inspect. For diagnosing the cut-off page in "Open as host". Kotlin not compiled here.
- **v2.52.0** — files and chat messages the host deletes, renames, moves, uploads or saves now disappear from every open web page within ~4 s (no reload); Chat, Send and Help are only in the side panel (removed from the top bar); the side panel on the web can shrink to an icon rail (with unread badges); older Android browsers: `inset:` replaced by top/right/bottom/left; Android side panel scrolls on short screens and "Open my share as host" says so when sharing is off. Kotlin not compiled here.
- **v2.51.0** — Chat, Send, Help and Play (side panel, header buttons) now open as a tab inside the workspace instead of a floating window, and close back cleanly. Android side panel: "Open my share as host" (full host rights, in-app) and "Join a friend" (type their address, opens in the app). Modular: Android side panel and join dialog moved to `SidePanel.kt`, new strings in English + Hindi, `ARCHITECTURE.md` (modules and how to add a language), optional Rust crate `rust/localshare-core` (path check, MIME sniff, ID3 cover; tested with `cargo test`, not used by the app yet and never on the transfer path). Kotlin and Rust-on-Android parts not compiled here.
- **v2.50.0** — Hindi (web page: auto by browser language or a switch in the side panel; Android: bottom-bar and side-panel labels), warning on open Wi-Fi networks (Android 12+), slow-request log in the support log, wide-screen content width on Android, web page split into style.css, ux.css, app.js and menu.js (no behaviour change), labels on the file inputs, JVM unit tests for covers (`./gradlew testDebugUnitTest`), CI runs unit tests, lint and builds on version tags, `tools/make-keystore.sh`, Play data-safety answers and an F-Droid template. Kotlin parts not compiled here.
- **v2.49.0** — on-phone support log (crashes are saved; Settings > About has Copy log and Clear), the shown address refreshes the moment Wi-Fi or the hotspot changes, a plain warning when no password is set (the link is not encrypted), and a GitHub workflow that runs the 397-check harness on every push. Kotlin parts not compiled here.
- **v2.48.0** — side panel on the web page (brand, Upload, Files/Chat/Send/Games/Screen/TV remote/Help, and the workspace list; permanent on wide screens, a slide-over with a ☰ button on phones) and in the Android app (permanent on tablets/landscape, a drawer on phones). Same onyx + accent design tokens everywhere. Kotlin part not compiled here (no Android SDK in the build sandbox).
- **v2.47.0** — YouTube-style home grid (plain 16:9 thumbnails, names underneath, no boxes). Development (debug) builds let every signed-in device edit text files without a permission.
- **v2.46.0** — workspaces are now full copies of the app (own folder, own open file; a file opens only in the workspace you are in). Video and music keep playing in the background when you switch. Audio and document cards show their cover / preview image. A background video moving to its next clip no longer pulls you back.
- **v2.45.0** — workspaces replace the single viewer: Workspace 1 is Files, 2–6 hold videos, code, PDFs, docs and pictures (Settings gear sets the count, Alt+1..6 jumps). Music is now a pill at the top with a tools panel. Pictures use Viewer.js (MIT).
- **2.44.2** – The tab system is gone for real: no tab bar, dock, floating windows, saved layouts, "Files" tab or tab buttons. One viewer at a time; ⋮ → "Open in new browser tab" for another tab.
- **v2.44.1** — fix for the black, empty file list in the in-app browser: file cards are no longer skipped by the browser to save work (that left them blank), and the fade-in can no longer leave the list invisible
- **v2.44.0** — tabs removed: one viewer at a time (the back arrow closes it) and no tab bar, New tab, dock or window buttons; every file and folder menu has "Open in new browser tab" (opens that file in our video, music, image, PDF, Word or code viewer in a separate browser tab); video playlist sidebar like YouTube (folder name, position, numbers, playing marker, scrolls to the current video); custom slim scrollbar
- **v2.43.1** — fixes: the stray file name and tiny buttons that showed above videos and other tabs are gone (window-mode and floating-player styles were missing); the top bar and toolbar fit on phones (title and host picture hidden when narrow, Zip is icon-only, Upload stays on the same row); the first-run set-up screens no longer sit under the status and navigation bars
- **v2.43.0** — things where you would expect them: app Home puts Shared folders under Status, the invite/QR card right after it while sharing, and the permission warning at the top; side rail regrouped (Share, People, Tools); page has one Play button (Orb Arena or Arcade), Log out inside your avatar menu, a labelled Send button, search first in the toolbar, and a Tabs / New tab button in the top bar instead of the floating one (the old floating button is still an option in its settings)
- **v2.42.2** — layout fixes in the page: the music mini-player no longer covers the upload, arcade and back-to-top buttons; the top bar fits narrow phones (logout was cut off and the host picture overlapped your avatar)
- **v2.42.1** — security fixes from a bug-hunter scan: hidden files (names starting with a dot) can no longer be opened, edited or deleted by typing their path; DOCX/Markdown previews now only keep safe links (http, https, mailto, tel); a malformed party-chat message can no longer crash its thread
- **v2.42.0** — tabs, dock and floating player stay hidden until you are signed in (and are cleared on sign-out); open tabs come back after a refresh; at most 8 tabs (oldest idle one closes); floating video keeps all player controls and can pop out over other apps
